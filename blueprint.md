
# Lotto Number Generator

## Overview

A simple, visually appealing web application to generate random lottery numbers. The application will feature a clean, modern interface and provide a history of generated numbers.

## Project Outline

*   **index.html**: Main application structure, including the title, number display, generation button, and history log.
*   **style.css**: Modern styling with a focus on a clean layout, appealing fonts, and subtle visual effects like shadows and textures.
*   **main.js**: JavaScript logic for generating unique random numbers, displaying them, and maintaining a history of previous generations.

## Current Plan

1.  **Modify `index.html`**: Set up the basic structure for the lottery number generator.
2.  **Modify `style.css`**: Apply modern and visually appealing styles.
3.  **Modify `main.js`**: Implement the core logic for number generation and history.
